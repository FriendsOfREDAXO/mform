# Barrierefreiheit: Metadaten-Prüfung für Medien

Ab MForm 10 können Medien-Felder prüfen, ob die ausgewählten Dateien im Medienpool die nötigen Metadaten haben, allen voran den ALT-Text. Die Prüfung ist **opt-in** pro Feld, läuft zur Laufzeit gegen den Medienpool und ändert **keine gespeicherten Daten**: Weder das MForm-Speicherformat noch die REDAXO-Werte werden angefasst.

## Aktivieren

Die Option heißt `a11y` und wird wie `label` übergeben. Kurzform mit Feldnamen:

```php
$mform->addMediaField(1, ['label' => 'Bild', 'a11y' => ['med_alt']]);
$mform->addMedialistField(2, ['label' => 'Galerie', 'a11y' => ['med_alt', 'med_copyright']]);
```

Vollform mit eigener Meldung je Feld und optionalem striktem Modus:

```php
$mform->addMediaField(1, [
    'label' => 'Bild',
    'a11y' => [
        'required_media_meta' => [
            ['field' => 'med_alt', 'message' => 'Bitte ALT-Text im Medienpool ergänzen.'],
            ['field' => 'med_copyright', 'message' => 'Copyright fehlt.'],
        ],
        'strict' => true,
    ],
]);
```

Unterstützte Felder: `addMediaField()`, `addMedialistField()`, `addMFormMediaField()`, `addMFormMedialistField()`, `addImagelistField()` (Option im Parameter-Array) sowie `addCustomLinkField()` und `addCustomLinkMultipleField()` (Option in den Attributen, geprüft werden Medien-Links). Die Prüfung funktioniert im klassischen Formular und in Flex-Repeater-Items.

## Was geprüft wird

| Feld | Regel |
|---|---|
| `med_alt` | Nur bei Bildern. Erfüllt, wenn ALT-Text vorhanden ist oder das Bild als dekorativ markiert wurde. Mit installiertem [MediaPlace](https://github.com/FriendsOfREDAXO/mediaplace) zählt dessen ALT-Status (eigenes ALT-Feld mit „dekorativ“ oder klassisches `med_alt` mit `med_alt_decorative`); ein gefülltes klassisches `med_alt` gilt immer. Ohne MediaPlace gilt ein gesetztes Metainfo-Feld `med_alt_decorative` ebenfalls als erfüllt. |
| `med_*` | Jedes Metainfo-Feld des Medienpools: erfüllt, wenn nicht leer. Mehrsprachige Felder aus [metainfo_lang_fields](https://github.com/FriendsOfREDAXO/metainfo_lang_fields) (`lang_text`, `lang_textarea`, `lang_text_all`, `lang_textarea_all`) werden je Online-Sprache geprüft, die Meldung nennt die fehlenden Sprachen. |
| `mediaplace:<key>` | Eigene MediaPlace-Metadaten (JSON-Feld). Übersetzbare Felder je Online-Sprache, das ALT-Widget mit „dekorativ“. Felder „nur für Bilder“ werden bei anderen Dateitypen übersprungen. |

Ein Feld, das es im Medienpool nicht gibt, wird als Konfigurationsfehler gemeldet (Meldung „Metainfo-Feld gibt es nicht“), unabhängig von der Modul-Meldung. Eine Datei, die nicht im Medienpool liegt, wird ebenfalls gemeldet.

## Verhalten im Formular

- Nach Auswahl einer Datei (oder beim Laden) fragt das Widget die API `mform_a11y_check` und zeigt das Ergebnis direkt unter dem Feld: eine Liste mit Datei, Meldung und dem Link „Metadaten bearbeiten“ (öffnet den Medienpool in einem neuen Tab, mit MediaPlace dessen Detailansicht). Sind alle Regeln erfüllt, erscheint ein kurzer grüner Hinweis.
- Bei Listen (Medialist, Bildliste, Custom Link Multiple) wird jede Datei einzeln geprüft.
- `strict => true` blockiert das Speichern des Blocks, solange Befunde offen sind. Ohne `strict` ist die Prüfung ein Hinweis, gespeichert werden kann immer.
- Die API ist nur für angemeldete Backend-Benutzer erreichbar und prüft ausschließlich `med_*`- und `mediaplace:`-Felder.

## Technik

Die Option landet als `data-mform-a11y` (Regeln als JSON) und optional `data-mform-a11y-strict` an der `form-group` des Feldes; `assets/js/a11y-check.js` sammelt daraus die Dateinamen, ruft die API und rendert die Hinweise. Serverseitig prüft `FriendsOfRedaxo\MForm\A11y\MediaMetaChecker`, der auch direkt nutzbar ist:

```php
use FriendsOfRedaxo\MForm\A11y\MediaMetaChecker;

$checker = new MediaMetaChecker();
$result = $checker->check('bild.jpg', [['field' => 'med_alt', 'message' => '']]);
// $result['issues'] => [] wenn alles erfüllt
```
